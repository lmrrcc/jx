# JX artwork

[jx-banner.png](jx-banner.png) is the 1731 × 909 pixel cover used by the project
README and suitable for a landscape social post. Its palette comes from the
[Todo application stylesheet](../../examples/todo-app/src/main/web/styles.css):

| Role | Color |
| --- | --- |
| Warm ivory background | `#f5f4ef` |
| Forest text | `#24352d` |
| Primary green | `#2e5543` |
| Sage surface | `#e8ece3` |
| Terracotta accent | `#bd713d` |
| Muted text | `#6d7a6f` |
| Dividers | `#d9dfd5` |

The serif headline, quiet surfaces, and light code panel follow the Todo app's
visual direction. The counter uses the current `@JxComponent` annotation.

Created with the built-in image generation tool using the user's previous cover
as the composition reference. The full [generation prompt](banner-prompt.txt)
records the text, layout, and palette. Code is promotional artwork; the README's
selectable code block and repository examples are the source to copy and compile.
